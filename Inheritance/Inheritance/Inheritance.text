** Inheritance **

Inheritance is an OOP concept in which a derived class inheris accessible members (methods & properties) from its base class. It allows code 
reuseability.
It cannot directly access private members.

class Employee
{
    public string Name { get; set; } = "";

    public void Work()
    {
        Console.WriteLine("Employee is working");
    }

    private double salary = 50000;
}

class Developer : Employee
{
    public void WriteCode()
    {
        Console.WriteLine("Developer is coding");
    }
}

Interview-ready definition
Inheritance is an OOP principle in which a derived class inherits accessible members of a base class, 
promoting code reusability and establishing an “is-a” relationship.


** What is "is-a" & "has-a" relationship?

Ans - is-a
A class is a type of category; it is usually represented through inheritance.

    has-a
